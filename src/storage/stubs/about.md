# About

This is an **About** page. Standalone pages live in the `pages/` directory
and are available at their URL path, e.g. this file (`pages/about.md`) is
served at `/about`.

Pages placed in subdirectories map to that path as well — for example,
`pages/projects/foo.md` is served at `/projects/foo`.
