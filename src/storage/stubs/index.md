# 👋 Welcome!

Welcome to your brand new **StupidGreen** blog! StupidGreen is a fast, compiled static
blog generator written in [Nim](https://nim-lang.org), powered by
[Supranim](https://supranim.com), [Tim](https://github.com/openpeeps/tim) and
[Marvdown](https://github.com/openpeeps/marvdown).

## Getting started

1. Create a new post by running `stupidgreen post "My first post"` in your terminal.
2. Write your content in Markdown. Each post lives in the `posts/` directory.
3. Add metadata to the YAML front matter at the top of the file:

```markdown
---
title: "My first post"
date: 2026-01-01
tags: [nim, blogging]
---
```

4. Run `stupidgreen run --sync` to preview your blog with live-reload.
5. Run `stupidgreen build` to generate a fully static website.

## Features

- ✍️ Write in plain Markdown with YAML front matter
- 🏷️ Tags & categories with archive pages
- 📡 RSS/Atom feed generation
- 🗺️ Sitemap generation
- 🔎 Client-side search
- 📖 Reading time estimation
- ⚡️ Blazing fast static output

Enjoy blogging!
